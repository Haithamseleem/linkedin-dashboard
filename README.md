# LinkedIn Autopilot · Control desk

A static control panel for the private `Haithamseleem/linkedin-autopilot` repo. It holds no data: posts, settings and history load from that repo through the GitHub API after you sign in with a fine-grained token, which stays in your browser.

Token: Fine-grained, **Only select repositories → linkedin-autopilot**, with **Contents**, **Actions** and **Variables** set to *Read and write*.

Sample view without signing in: add `?demo=1` to the address.

Three.js is bundled in `vendor/` (MIT, see `vendor/three-LICENSE.txt`).
